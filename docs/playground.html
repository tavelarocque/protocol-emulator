Protocol Emulator: playground

Pick a protocol, change its firmware, and run it. The program is assembled and run here, in the page, on the project's reference model; the pins come back as a waveform and the words the threads hand the host come back as a table.

The reference model, in your browserThis is model/isa.ml and the assembler, compiled to JavaScript: the same code the tests check the RTL against every cycle, and the same run as the command-line pe_sim, which a test compares with this build line for line. The tests judge firmware with sigrok's decoders, not with this page. The chip is designed for tapeout; nothing here has run on an FPGA or on silicon.

The programs are the files in examples/, generated from model/firmware.ml; each preset's configuration, TX words and stimulus are the ones its test uses, and each was run and checked on the native model when this page was built.
