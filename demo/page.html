Protocol Emulator: firmware on the bench

One small two-thread CPU whose instructions read pins, write pins and count clock cycles. Each protocol here is a program loaded into it, shown running on the project's reference model. To change a program and run it yourself, open the playground.

Status: simulation onlyEvery waveform is a recorded run of the reference model. The chip is designed for tapeout and has not been fabricated, and the board in Figure 1 is a drawing.

    Made by bin/demo_traces.ml from model/isa.ml and model/firmware.ml, the model and the firmware the test suite runs. Each capture is checked as the page is built, and a failed check stops the build. Set in IBM Plex. Source, tests and proofs. To edit the firmware and run it on the reference model in your browser: playground.html.
